# EDY Sentinel v1.0.0

EDY Sentinel brings local-first Windows telemetry, explainable detections, conservative
vulnerability intelligence, and an auditable Security Score into one desktop application.

## Download

**Recommended:** `EDY-Sentinel-1.0.0-Setup-x64.exe`

| Asset | Use |

| `EDY-Sentinel-1.0.0-Setup-x64.exe` | Recommended interactive installer |
| `EDY-Sentinel-1.0.0-x64.msi` | Managed or conventional Windows installation |

> **Unsigned build:** the v1.0.0 Windows binaries do not carry an Authenticode publisher signature
> or trusted timestamp. Windows can display an unknown-publisher warning. Verify the SHA-256 hashes
> below and do not represent these files as signed or publisher-authenticated.

## Highlights

- Native, read-only Windows system, process, TCP/UDP connection, service, route, adapter, DNS, and
  installed-software collection with explicit unavailable and restricted states.
- A versioned behavioral baseline and factual Security Events kept separate from explainable
  rule-produced Detections.
- Detection Engine v1 with six enabled rules, immutable provenance, bounded correlation,
  exclusions, evidence, deduplication, reopen behavior, and workflow history.
- Security Score formula v2 with separate Detection and confirmed-vulnerability contributions,
  explicit coverage, formula-versioned history, and no penalty for Possible matches.
- Conservative Product Identity/CPE resolution and NVD applicability evaluation, with CISA KEV as
  post-match prioritization context only.
- English and Português (Brasil), Sentinel Blue, Cyber Green, Terminal, and Spectrum themes.

## Requirements and installation

- Windows 10 or Windows 11, x64.
- Microsoft Edge WebView2 Runtime.
- Standard-user runtime. The per-machine MSI can request elevation only for installation.
- Internet access is optional for normal local operation and required only to synchronize public
  NVD/CISA data.

For most users, download and run the Setup EXE, then open EDY Sentinel from the Start menu. MSI is
provided for managed installation. MSI and silent NSIS uninstall preserve application data. The
interactive NSIS uninstaller offers an explicit, unchecked `Delete app data` option.

## Local data and offline behavior

The authoritative `sentinel.db` and reconstructible `vulnerability-cache.db` are stored under
`%APPDATA%\com.edy.sentinel`. Treat them as sensitive endpoint metadata. Telemetry, Inventory,
baseline, Security Events, Detections, scores, preferences, and materialized vulnerability evidence
remain local and usable offline. Only provider synchronization requires HTTPS.

Process command lines are not persisted, file contents are not collected, and endpoint inventory
or telemetry is not uploaded to NVD or CISA. EDY Sentinel 1.0.0 includes no product analytics or
proprietary cloud telemetry.

## Audited host example

The final local review observed Security Score 86 = 100 − Detections 0 − Vulnerabilities 14 under
formula version 2, with 31 Confirmed CVEs, one Possible CVE with zero impact, and one Confirmed CISA
KEV entry. These are real results from the reviewed endpoint, not fixed demo data or a universal
expected state. Results vary by endpoint and available coverage.

## Known limitations

- Authenticode publisher identity and trusted timestamp verification are not present in v1.0.0.
- Product identity deliberately fails closed when vendor, product, version, or applicability
  evidence is ambiguous.
- The six local rules are conservative observability rules, not full EDR or malware classification.
- The Security Score is an explainable posture indicator, not a guarantee.
- Automated response, process/network blocking, firewall/service control, external reputation,
  and advanced network scanning are outside v1 scope.
