# Roadmap

## Sprint 0 — Foundation (current)

- Tauri 2, React, TypeScript, and Rust workspace
- Real Windows system and network collection
- Typed IPC and honest partial/error states
- SQLite migrations, snapshots, and persisted theme
- Premium responsive shell and four themes
- Security, build, and contributor documentation

## Recommended Sprint 1

Build a local snapshot scheduler and an explainable Baseline Engine. Establish retention, compare trusted historical values, and emit evidence-backed change events. Do not compute a composite Security Score yet.

## Later increments

1. Process, connection, service, and software collectors
2. Device discovery with conservative local-network controls
3. Detection rules, alerts, and event investigation
4. Reports and opt-in integrations
5. Vulnerability and threat-intelligence sources with secure credentials
6. Explainable Security Score after evidence, calibration, and tests exist

## Explicit non-goals for Sprint 0

VirusTotal, AbuseIPDB, HIBP, urlscan, NVD/CISA, advanced network scanning, CVE matching, and AI are not started.
